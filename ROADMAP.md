# Roadmap

This roadmap keeps Tokenomics from Scratch focused on practical AI product economics rather than becoming a general AI engineering repository.

## Phase 0: First Public Commit

- Build the Markdown-first curriculum structure.
- Add complete lessons for foundations, token math, and cost per completed task.
- Add placeholder lesson pages for the remaining phases.
- Ship a small Python calculator and routing simulator with tests.
- Add PM and FDE templates that can be reused in interviews, customer discovery, and implementation planning.
- Clearly mark all sample pricing as illustrative.

## Phase 1: Cost Foundations

- Expand token math examples for cached tokens, batch pricing, embeddings, and multimodal inputs.
- Add worked examples for support, summarization, internal copilot, and extraction tasks.
- Add a spreadsheet-friendly cost model template.

## Phase 2: Routing And Budgeting

- Add confidence-based routing examples inspired by cascade patterns.
- Add budget policy templates for free, team, and enterprise tiers.
- Add scorecards for choosing cheap, mid-tier, and frontier models.

## Phase 3: Agent Economics

- Add agent trace examples that show planning, tool calls, retries, and reflection loops.
- Add a turn-limit planning worksheet.
- Add examples for human fallback and failure cost.

## Phase 4: Observability And Governance

- Add tracing schema examples for cost per completed task.
- Add eval gates for latency, quality, and estimated cost.
- Add guidance for pricing review cadence and model-price change management.

## Phase 5: Feature Margin

- Add an AI feature P&L template.
- Add pricing strategy examples for flat subscription, metered usage, and outcome-based billing.
- Add launch-readiness examples that connect product scope to margin targets.

## Phase 6: Capstone Artifacts

- Create a complete AI feature economics report example.
- Add a dashboard-style Markdown artifact that pulls together cost, quality, routing, fallback, and margin assumptions.

## Not Planned For V0

- Live provider integrations
- API-key based examples
- Full web app
- Production billing system
- Large framework dependencies
- Provider-specific price claims without validation
