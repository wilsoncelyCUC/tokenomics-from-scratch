# Resources

This folder is curated for AI product economics. It is not an awesome-list.

Every resource should pass at least one test:

- Helps estimate real AI system cost
- Explains agentic workflow economics
- Provides reusable pricing data
- Helps evaluate cost-quality tradeoffs
- Is an open-source tool product builders can actually use
- Provides a strong strategic concept for AI product economics
