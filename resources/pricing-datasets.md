# Pricing Datasets

Static prices become stale quickly. Treat every price as an assumption with a source and date.

| Resource | Status | Why It Matters |
| --- | --- | --- |
| [Pydantic GenAI Prices](https://github.com/pydantic/genai-prices) | needs validation | Candidate source for machine-readable provider pricing data. |
| Portkey model pricing resources | needs validation | Candidate source for comparing provider and model pricing. |
| [Simon Willison LLM Prices](https://www.llm-prices.com/) | needs validation | Candidate reference for quick model price comparisons and pricing intuition. |

## Pricing Review Checklist

- Source URL
- Date checked
- Model version
- Input price
- Output price
- Cached input rules
- Batch pricing rules
- Context-window thresholds
- Region or account caveats
