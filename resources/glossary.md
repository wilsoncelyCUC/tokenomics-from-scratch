# Tokenomics Glossary

## Core Terms

**AI feature margin**: Revenue attributed to an AI feature minus the variable costs required to deliver it.

**Batch pricing**: A discounted pricing mode for asynchronous jobs that do not need immediate responses.

**Cached token**: A repeated input token that may be billed at a lower rate when a provider's cache rules are met.

**Context window**: The maximum amount of input and generated state a model can process in one request.

**Cost per completed task**: The total expected cost required to produce one successful user outcome.

**Failure cost**: The financial or operational cost of an AI task producing an unusable or harmful result.

**Fallback**: A planned escalation path, often to a stronger model, a human, or a safer workflow.

**Frontier model**: A top-capability model that is usually more expensive and often reserved for complex or high-value tasks.

**Human fallback rate**: The percentage of tasks expected to require human review or completion.

**Input token**: A token sent to a model, including instructions, user content, retrieved context, examples, and tool schemas.

**Model cascade**: A routing pattern that attempts a task with a cheaper model and escalates only when needed.

**Model routing**: The practice of selecting a model based on task type, budget, quality target, latency target, or customer tier.

**Monthly volume**: The expected number of completed tasks in a month.

**Output token**: A token generated by a model.

**Reasoning token**: A token consumed by a reasoning process, whether visible or hidden, depending on model and provider.

**Retry rate**: The percentage of tasks expected to repeat one or more workflow steps.

**Task budget**: The maximum acceptable cost for completing one task.

**Tool call**: A call from an AI workflow to an API, database, code interpreter, browser, or other external capability.

**Trace**: A structured record of the steps, costs, model calls, and outcomes inside an AI workflow.
