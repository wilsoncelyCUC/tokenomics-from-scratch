# Cost Per Task Calculator

This demo calculates cost per completed task for the support-agent example.

Run:

```bash
python projects/cost-per-task-calculator/calculator.py
```

Or use the package CLI:

```bash
python -m tokenomics_from_scratch.cli estimate --workflow examples/support-agent-cost.json
```

The demo uses illustrative pricing from [data/sample_pricing.json](../../data/sample_pricing.json).
