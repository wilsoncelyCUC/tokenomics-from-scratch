# Launch Readiness Checklist

## Economics

- [ ] The completed task is clearly defined.
- [ ] Cost per completed task is estimated.
- [ ] Monthly volume assumptions are documented.
- [ ] Retry and fallback assumptions are documented.
- [ ] Failure cost is estimated.
- [ ] Feature margin is reviewed.

## Routing

- [ ] Default model is selected.
- [ ] Fallback model is selected.
- [ ] Budget threshold is defined.
- [ ] High-risk tasks have escalation rules.

## Observability

- [ ] Workflow ID is logged.
- [ ] Step costs are logged.
- [ ] Input and output tokens are logged.
- [ ] Retry count is logged.
- [ ] Human fallback is logged.
- [ ] Outcome quality is logged.

## Governance

- [ ] Pricing source and date checked are recorded.
- [ ] Next pricing review date is set.
- [ ] No API keys or secrets are committed.
- [ ] Sample data is marked as illustrative.
